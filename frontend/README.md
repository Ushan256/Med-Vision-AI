# Medical AI Imaging Frontend

React frontend for the Medical AI Imaging application with chest X-ray pneumonia classification.

## Features

- **Image Upload**: Upload chest X-ray images for analysis
- **Confidence Meter**: Visual progress bar showing AI confidence level
- **Grad-CAM Heatmap**: Visual explanation of AI decision-making
- **Medical Disclaimer**: Prominent footer with research disclaimer

## Setup

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm run dev
```

The app will be available at `http://localhost:3000`

## Build for Production

```bash
npm run build
```

## Requirements

- Node.js 16+ 
- Backend API running on `http://localhost:8000`
